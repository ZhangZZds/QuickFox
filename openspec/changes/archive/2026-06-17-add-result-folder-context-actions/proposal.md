## Why

搜索结果右键菜单已经提供“复制路径”和部分打开动作，但用户在定位文件时经常需要复制父目录路径，或直接打开结果所在文件夹。当前文件结果有“打开所在目录”，目录结果只有打开自身和复制自身路径，缺少明确的“所在文件夹”相关动作。

## What Changes

- 文件和目录结果的右键动作菜单增加“复制所在文件夹路径”。
- 文件和目录结果的右键动作菜单增加“打开所在文件夹”。
- 文件结果保留现有“打开所在目录”“复制路径”“选择打开方式”语义。
- 目录结果保留现有“打开文件夹”“复制路径”语义，同时可对其父目录执行新增动作。

## Impact

- Rust core: 搜索结果 secondary actions 需要按结果路径计算父目录并返回 `copyText` / `openPath` 动作。
- Frontend: 右键菜单 action label 需要区分“复制路径”和“复制所在文件夹路径”，以及区分目录自身打开和父目录打开。
- Tests: Rust Provider/Index 结果动作测试和前端右键菜单测试需要覆盖新增动作。
