## MODIFIED Requirements

### Requirement: 结果动作菜单

系统 SHALL 为支持次要动作的结果提供动作菜单，用户可以通过右键或键盘快捷键打开该菜单，并且菜单位置应靠近触发的结果项。

#### Scenario: 右键打开动作菜单

- **WHEN** 用户右键点击一个文件或目录结果
- **THEN** 系统在该结果项附近显示其可用的次要动作列表

#### Scenario: 动作菜单执行次要动作

- **WHEN** 用户在动作菜单中选择“复制路径”
- **THEN** 系统复制该结果对应路径

#### Scenario: 动作菜单执行所在文件夹动作

- **WHEN** 用户在文件或目录结果动作菜单中选择“复制所在文件夹路径”
- **THEN** 系统复制该结果父目录路径
- **WHEN** 用户选择“打开所在文件夹”
- **THEN** 系统打开该结果父目录
