## Why

当前搜索结果行只有悬停选中和右键菜单，左键点击不会执行打开动作；Enter 也依赖搜索输入框焦点，用户在点击结果后再按 Enter 容易误以为文件无法打开。QuickFox 需要明确不同搜索结果类型的主激活行为，并让鼠标和键盘执行同一语义。

## What Changes

- 明确定义搜索结果的主激活语义：左键单击结果行和 Enter 激活当前选中结果时，均执行该结果的主动作。
- 文件夹、文件、应用结果的主动作均保持由 Rust core 提供并执行，前端不按平台或扩展名自行选择打开方式。
- 文件结果使用系统默认关联应用打开；目录结果打开目录；应用结果启动应用；网页、计算器、命令等非文件结果继续使用其现有主动作。
- 右键动作菜单继续只用于次要动作，不因新增左键激活而改变菜单内容。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `launcher-shell`: 明确结果行左键点击和 Enter 激活当前选中结果的行为。

## Impact

- 前端 `src/App.tsx` 需要抽出统一结果激活入口，并将结果行左键点击接入该入口。
- 前端测试 `src/App.test.tsx` 需要覆盖左键点击、Enter 与不同结果类型的主动作一致性。
- Rust core 现有 `openPath` / opener 跨平台路径保持不变；本次不新增平台 Adapter 或依赖。
