## MODIFIED Requirements

### Requirement: 设置页提供字段级帮助提示

系统 SHALL 在设置页重要配置项旁提供小问号帮助图标，并在悬停或键盘聚焦时显示简短说明。帮助
提示 MUST 作为不受父级滚动或裁切影响的窗口级浮层显示，并根据可用空间避开窗口边缘。

#### Scenario: 鼠标悬停显示配置说明

- **WHEN** 用户将鼠标移到设置字段旁的问号图标上
- **THEN** 系统显示该字段如何配置和注意事项的提示，例如多目录配置使用一行一个完整路径
- **AND** 提示不常驻占用设置页面空间
- **AND** 提示不被设置面板、分区卡片或滚动容器裁切

#### Scenario: 键盘聚焦显示配置说明

- **WHEN** 用户通过键盘聚焦到问号图标
- **THEN** 系统显示同样的帮助提示
- **AND** 问号图标具有可访问名称

#### Scenario: 帮助提示提供可执行示例

- **WHEN** 用户查看索引目录、排除目录、排除模式、正则前缀或全局唤醒键说明
- **THEN** 帮助提示包含具体输入格式或示例
- **AND** 用户无需猜测多个目录、多条规则或快捷键应该如何填写

#### Scenario: 提示在窗口边缘保持完整可读

- **WHEN** 用户悬停或聚焦的问号图标靠近窗口上、下、左或右边缘
- **THEN** 系统将提示放在可用的上方或下方空间，并将其水平位置限制在窗口可见区域内
- **AND** 用户可以阅读完整提示内容

#### Scenario: 滚动后提示保持锚定

- **WHEN** 帮助提示已显示且所属设置内容区或任意祖先滚动容器发生滚动
- **THEN** 系统重新计算提示位置，使其继续锚定问号图标
