# Windows 手工验收清单

## 快捷键与窗口

- 双击 Shift 能唤起启动窗口
- 再次触发能隐藏窗口或将焦点切回启动器
- Esc 能关闭窗口
- 窗口出现时输入框自动聚焦

## 搜索与结果

- 普通文件/目录搜索能返回结果
- 正则搜索 `re:` 行为正常
- 方向键切换结果稳定
- Enter 执行主动作
- 右键菜单能打开所在目录、复制路径

## 命令执行

- `>` 查询能进入命令预览
- 关闭命令执行时能看到禁用提示
- 开启命令执行后，普通命令需要确认
- 危险命令会阻止或要求更强确认
- Windows Terminal 能被正确拉起

## 权限与提示

- 提权或系统修改命令能看到风险提示
- 被阻止的命令不会静默执行

## 历史与设置

- 基础设置可打开
- 命令开关状态可生效
- 命令历史条数调整后行为符合预期

发现问题后，建议记录：

- Windows 版本
- 终端版本
- 复现步骤
- 预期行为与实际行为
