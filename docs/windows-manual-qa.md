# Windows 手工验收清单

## 快捷键与窗口

- 双击 Shift 能唤起启动窗口
- 后台窗口再次双击 Shift 能置前并聚焦输入框
- 已显示窗口再次双击 Shift 能隐藏窗口
- Esc 能关闭窗口
- 窗口出现时输入框自动聚焦
- 快速启动窗口内不显示设置按钮
- 托盘菜单“设置”能打开设置页

## 搜索与结果

- 普通文件/目录搜索能返回结果
- 正则搜索 `re:` 行为正常
- 输入不存在查询时不会返回明显不相关结果
- `.exe` 和开始菜单 `.lnk` 作为应用结果，且排序优先于普通文件和目录
- 方向键切换结果稳定
- Enter 执行主动作
- 右键菜单能打开所在目录、复制路径
- 右键菜单出现在被点击结果附近
- 空输入时不显示多余结果区域留白

## 网页搜索与索引

- `g 1234` 能生成 Google 搜索结果并用默认浏览器打开
- `bd 1234` 能生成百度搜索结果并用默认浏览器打开
- 设置页“搜索与索引”分组能触发刷新索引
- 增量刷新后新增/删除文件能反映到搜索结果

## 命令执行

- `>` 查询能进入命令预览
- 关闭命令执行时能看到禁用提示
- 开启命令执行后，普通命令需要确认
- 危险命令会阻止或要求更强确认
- Windows Terminal 能被正确拉起

## 权限与提示

- 提权或系统修改命令能看到风险提示
- 被阻止的命令不会静默执行

## 历史与设置

- 设置页可从托盘菜单打开
- 设置页按“搜索与索引”“网页搜索”“历史”“命令执行”“外观与窗口”分组
- 命令开关状态可生效
- 最近输入条数调整后行为符合预期
- 上/下方向键能召回最近 15 条确认执行过的文件、目录、命令和网页搜索输入
- 只输入但未按 Enter 执行时不会记录历史

- 复现步骤
- 预期行为与实际行为
