# Windows 手工验收清单

## 快捷键与窗口

- 发布版启动后不弹出额外 cmd/console 窗口
- 双击 Shift 能唤起启动窗口
- 设置页“外观”中能把全局唤醒键录制为 `Control+Space` 等组合键；保存后新组合键能唤起/隐藏启动器
- 设置页“外观”中尝试录制 `Alt+Space` 时显示系统占用提示，且不会把它保存为新的唤醒键
- 设置页拒绝只按单个修饰键作为唤醒键
- 将全局唤醒键设置为 `Shift+Space` 后，在任意文本框中用 Shift 输入大写字母、松开后继续输入 Space，不应唤起或隐藏 QuickFox
- 将全局唤醒键设置为 `Shift+Space` 后，故意慢按 Shift、停顿超过半秒再按 Space，不应唤起或隐藏 QuickFox
- 后台窗口再次双击 Shift 能置前并聚焦输入框
- 已显示窗口再次双击 Shift 能隐藏窗口
- 启动器失去焦点时自动隐藏到后台
- Esc 能关闭窗口
- 窗口出现时输入框自动聚焦
- 快速启动窗口内不显示设置按钮
- 快速启动窗口呈现为紧凑浮层，不显示设置页标题栏、设置导航或大块透明桌面背景
- 托盘菜单“设置”打开独立设置窗口，保留系统关闭、缩放和调整大小入口
- QuickFox 隐藏、最小化或在后台时，只保留托盘图标，不在任务栏呈现一个最小化窗口
- 托盘菜单“显示/隐藏 QuickFox”能显示隐藏的启动器，并能隐藏已聚焦的启动器
- 托盘菜单“显示/隐藏 QuickFox”后，再次按全局唤醒键的显示/隐藏行为与普通唤起一致
- 托盘菜单“设置”能打开设置页；关闭设置窗口后再次点击“设置”能重新创建并显示设置窗口

## 搜索与结果

- 普通文件/目录搜索能返回结果
- 正则搜索 `re:` 行为正常
- 输入不存在查询时不会返回明显不相关结果
- `.exe` 和开始菜单 `.lnk` 作为应用结果，且排序优先于普通文件和目录
- 方向键切换结果稳定
- Enter 执行主动作
- 右键菜单能打开所在目录、复制路径
- 右键菜单出现在被点击结果附近
- 空输入时不显示多余结果区域留白

## 网页搜索与索引

- `g 1234` 能生成 Google 搜索结果并用默认浏览器打开
- `ddg 1234` 能生成 DuckDuckGo 搜索结果并用默认浏览器打开
- `bd 1234` 能生成百度搜索结果并用默认浏览器打开
- 首次启动或大文件树启动时，启动器和托盘不被索引过程阻塞
- 默认 `balanced` 模式下，将索引目录设为 `C:\Users` 和 `D:\` 这类大目录后首次启动，应用入口和 Desktop/Downloads 等热路径先可搜索，启动器提示“文件搜索已部分可用”，随后后台补全大目录
- `fast` 模式下首次启动只扫描应用入口和热路径，不自动补扫 `D:\` 等配置大根目录；设置页应说明结果范围更窄
- `complete` 模式下首次索引覆盖完整配置范围；设置页应说明首次索引更慢但覆盖更完整
- 文件索引未完成时，启动器提示“文件索引正在建立”或对应失败信息
- 文件索引未建立、构建中或失败时，启动器提供“刷新索引”和/或“打开设置”恢复动作
- 后台索引完成后，当前普通查询能刷新为最新搜索结果
- 索引已建立后快速连续输入文件名，输入框不应卡顿，较早查询晚返回时不覆盖最新输入结果
- 基础文件索引可用但内容索引仍在准备时，普通 name/path 查询可返回结果；`content:` 查询显示内容索引准备中的反馈
- 设置页“搜索与索引”分组能触发后台刷新索引，并显示索引状态
- 设置页“搜索与索引”分组能显示配置文件完整路径和索引快照存储路径
- 设置页“搜索与索引”分组显示当前索引模式、阶段、当前 root、已扫描、收录、跳过和失败数量
- 增量刷新后新增/删除文件能反映到搜索结果
- 存在旧索引快照时，重启后能先使用旧索引搜索，同时后台更新索引

## 大索引性能验收

- 使用发布构建，不使用开发服务器或 debug build
- 将 name/path 索引范围配置为真实 Windows C/D 多盘大目录，例如 `C:\Users` 和 `D:\`；记录实际磁盘总量、扫描 root 和排除项
- 等待索引进入 ready 或 refreshing-but-available 状态；记录设置页显示的 entry count、当前 stage、scanned、accepted、skipped、failures
- 打开任务管理器记录 QuickFox 进程常驻内存；200 万文件级目标小于 500MB，硬上限小于 800MB，超过时必须记录截图和复现配置
- 在启动器连续输入 `agents.md`，特别观察输入到 `m` 时是否卡顿；录屏中应能看出输入框持续响应、旧搜索结果不会覆盖新输入
- 查询 `agents.md`、`agents.m`、`agents`、`type:md agents`、`dir:workspace agents`，目标文件应稳定在前 5 个结果内
- 查询一个不存在的长词，例如 `needle-not-present-987654321`，不应出现明显输入冻结或全量扫描造成的长时间空白
- 基础 name/path 可用但内容索引仍在准备时，普通查询仍返回结果；`content:` 查询显示内容索引准备中或合理降级
- 在 Windows 机器上运行 2,000,000 synthetic 阈值命令并保存输出：

```powershell
cargo test --release --manifest-path src-tauri/Cargo.toml `
  two_million_entry_search_stays_within_latency_budget `
  -- --ignored --nocapture
```

记录 `QUICKFOX_LARGE_INDEX_THRESHOLD` 输出、任务管理器内存截图、`agents.md` 输入录屏和结果截图。若无法在当轮执行，应在 issue 或 QA 记录中明确标注为待验收，不得将其等同于已通过。

## 命令执行

- `>` 查询能进入命令预览
- 关闭命令执行时能看到禁用提示
- 开启命令执行后，普通命令需要确认
- 危险命令会阻止或要求更强确认
- Windows Terminal 能被正确拉起

## 权限与提示

- 提权或系统修改命令能看到风险提示
- 被阻止的命令不会静默执行

## 历史与设置

- 设置页可从托盘菜单打开
- 设置页按“索引”“网页搜索”“历史”“命令安全”“外观”分区
- 设置页没有“返回搜索”按钮；保存后仍停留在设置窗口
- 设置页关键字段旁显示问号说明，鼠标悬停和键盘聚焦时出现提示
- 调整设置窗口宽度和高度时，内容改为单列或内部滚动，保存入口仍可访问且文本不重叠
- 网页搜索分区能新增 DuckDuckGo 等搜索引擎，缺少 `{query}` 的 URL 模板会被阻止保存
- 命令开关状态可生效
- 最近输入条数调整后行为符合预期
- 上/下方向键能召回最近 15 条确认执行过的文件、目录、命令和网页搜索输入
- 只输入但未按 Enter 执行时不会记录历史

发现问题后，建议记录：

- Windows 版本
- 终端版本
- QuickFox 构建类型和 commit
- 索引 entry count、扫描 roots、磁盘规模和任务管理器内存
- `QUICKFOX_LARGE_INDEX_THRESHOLD` 或未运行原因
- 复现步骤
- 预期行为与实际行为
