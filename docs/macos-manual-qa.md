# macOS 手工验收清单

本清单用于验证 `fix-launcher-manual-qa-bugs` 中无法完全自动化的桌面行为。

## 快捷键与窗口

- 首次运行后，如系统提示输入监控或辅助功能权限，给 QuickFox 授权并重启应用
- 双击 Shift 能在 QuickFox 隐藏时显示启动窗口
- QuickFox 在后台时双击 Shift 能置前并聚焦输入框
- QuickFox 已显示时双击 Shift 能隐藏窗口
- Esc 能关闭窗口且不执行当前结果
- 快速启动窗口内不显示设置按钮
- 托盘菜单“显示 QuickFox”能显示启动器
- 托盘菜单“设置”能打开设置页

## 搜索与结果

- 普通文件/目录搜索能返回相关结果
- 输入 `Openspec_123` 这类不存在查询时不会返回 PyCharm 内部资源
- `.app` 作为应用结果出现
- `.app/Contents` 内部文件不进入普通搜索结果
- 应用程序排序优先于文件和目录
- 空输入时不显示多余结果区域留白
- 右键菜单出现在被点击结果附近
- 搜索列表长内容只在列表内部滚动

## 网页搜索与索引

- `g 1234` 能生成 Google 搜索结果并用默认浏览器打开
- `bd 1234` 能生成百度搜索结果并用默认浏览器打开
- 设置页“搜索与索引”分组能触发刷新索引
- 增量刷新后新增/删除文件能反映到搜索结果

## 历史与设置

- 设置页按“搜索与索引”“网页搜索”“历史”“命令执行”“外观与窗口”分组
- 上/下方向键能召回最近 15 条确认执行过的文件、目录、命令和网页搜索输入
- 只输入但未按 Enter 执行时不会记录历史

## 命令执行

- `>` 查询能进入命令预览
- 关闭命令执行时能看到禁用提示
- 开启命令执行后，普通命令需要确认
- 危险命令会阻止或要求更强确认
- 命令通过 macOS Terminal 打开
