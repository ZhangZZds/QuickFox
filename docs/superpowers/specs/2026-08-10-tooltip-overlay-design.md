# 设置帮助提示框浮层设计

## 背景

设置内容区域使用 `overflow-y: auto` 提供滚动。帮助提示框是该区域的后代并向上绝对定位；CSS
会把其横向溢出同样裁切。因此鼠标悬停问号时，只会看到深色提示框的边缘，内容不可阅读。其他
拥有可滚动容器且复用该样式的页面也有相同风险。

## 目标

- 帮助提示框不受父级滚动容器裁切。
- 鼠标悬停和键盘聚焦都能查看完整内容。
- 提示框自动避开窗口的上下、左右边缘；滚动和窗口尺寸变化后位置正确。
- 统一复用一个帮助组件，避免按页面修补样式。

## 决策

将 `HelpIcon` 的内容通过 React portal 渲染到文档根部，并相对触发按钮使用 `position: fixed`
定位。组件打开时读取按钮的 `getBoundingClientRect()`；优先显示在按钮上方，顶部空间不足时显示在
下方，水平方向收束在视口边距内。组件在 hover、focus、滚动和 resize 时更新坐标，离开和失焦后
隐藏浮层。浮层使用 `role="tooltip"`，由触发按钮的 `aria-describedby` 关联。

不采用“始终向下显示”的纯 CSS 方案：底部字段仍会被滚动容器裁切，无法满足所有页面可阅读的
要求；也不取消内容区滚动，否则长设置页无法使用。

## 测试

- 帮助按钮 hover/focus 时提示框渲染在 portal 根部而非滚动内容内。
- 上方空间不足时提示框向下显示；下方空间不足时向上显示，且左右坐标保留窗口边距。
- 滚动、窗口调整大小后提示框重新定位；鼠标离开和失焦后隐藏。
- 设置页各标签继续可切换，原有帮助文本和保存行为不回归。
