# Esc 键逐层退出行为设计

## 背景

QuickFox 之前只在搜索输入框的 `onKeyDown` 中处理 Esc。结果行、动作菜单、设置页控件或快捷键录制按钮获得焦点后，Esc 不一定经过输入框事件，因此会出现按键没有可见效果。

## 目标

- Esc 在焦点离开搜索输入框后仍可用。
- Esc 先退出局部状态，再关闭启动器。
- Esc 不执行搜索结果、命令或次要动作，也不记录输入历史。
- 设置页常态不因 Esc 关闭，避免误触丢失配置上下文。

## 行为优先级

1. 正在录制全局唤醒快捷键时，Esc 取消录制并保留原快捷键。
2. 动作菜单打开时，Esc 关闭动作菜单并保持启动器打开。
3. 历史模式打开时，Esc 退出历史模式并保留当前输入。
4. 设置页弹层打开时，Esc 关闭弹层并保持设置页打开。
5. 普通启动器状态下，Esc 关闭启动器。
6. 设置页常态下，Esc 不关闭设置页。

## 实现方案

前端在 `App` 内提炼统一 `handleEscapeKey`，输入框和 document 级 keydown 兜底监听都调用它。快捷键录制函数在最前面截住 Escape，避免把 Escape 当作快捷键录制输入。

## 测试

- 焦点位于结果项时，Esc 关闭启动器且不执行动作。
- 动作菜单打开时，Esc 只关闭菜单。
- 快捷键录制中，Esc 取消录制并保留原配置。
- 设置页网页搜索新增向导打开时，Esc 关闭弹层。
- 设置页常态下，Esc 保持设置页打开。
