## 根因假设

- QF-001：当前窗口状态只记录 visible，不区分后台/前台，也没有 toggle 语义；
  Tauri 菜单事件把“设置”和“显示”都路由到同一个 show 方法。
- QF-002：普通模糊搜索没有最低相关性阈值，且索引扫描会进入 `.app/Contents`
  等应用内部资源。
- QF-003/QF-004/QF-010：结果列表和动作菜单定位依赖固定布局，空状态和滚动
  容器边界不清晰。
- QF-005：查询解析器当前使用 `g:` 语法，和维护者确认的 `g 1234` 不一致。
- QF-006/QF-011：设置入口和设置页只是 MVP 占位形态，没有按托盘/分类模型
  设计。
- QF-007：刷新索引命令存在，但设置页没有接入；索引刷新没有表达增量语义。
- QF-008：存储层只有命令历史，未实现确认执行过的通用输入历史。
- QF-009：Ranker 只看匹配、路径深度和历史，没有应用/文件/目录类型优先级。

## 跨平台验收

### macOS

- `.app` 应作为应用结果出现，`.app/Contents` 内部文件不进入普通搜索结果。
- 双击 Shift 在窗口隐藏、后台、前台三种状态下分别显示/置前/隐藏。
- 托盘菜单“设置”打开设置页，“显示 QuickFox”显示启动器。

### Windows

- `.exe` 和开始菜单 `.lnk` 作为应用结果。
- 双击 Shift 能显示/隐藏窗口，并聚焦输入框。
- Windows Terminal 执行命令路径仍正常。

### Linux

- `.desktop` 作为应用结果。
- 双击 Shift 能显示/隐藏窗口，并聚焦输入框。
- 终端 fallback 执行命令路径仍正常。

## 自动化边界

- Rust 单元测试覆盖查询解析、索引过滤、应用识别、排序、输入历史和窗口状态机。
- 前端测试覆盖设置入口、设置页分组、刷新索引、历史召回、空状态、右键菜单
  和列表滚动语义。
- 真实桌面置前、托盘菜单和全局快捷键在各平台手工验收。
